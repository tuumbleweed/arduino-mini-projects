# Matreshka Arduino Course

My Arduino projects from Amperka's Matreshka course book. I completed the first 12 of its 20 exercises.

The exercises cover LEDs, brightness control, sound, buttons, and a simple two-player reaction game. Each numbered folder contains an Arduino sketch and a README with circuit diagrams, photos, or a demonstration video.

To try an exercise, open its `sketch.ino` file in the Arduino IDE and follow the circuit diagram in that folder.
